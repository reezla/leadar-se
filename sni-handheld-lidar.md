# SNI codes for handheld LiDAR

Handheld LiDAR is most useful where people need a 3D model of an existing place they cannot measure well with a total station or tape: interiors, plants, tunnels, stockpiles, forest, and as-built BIM.

Codes below are SNI 2007 prefixes. In the app, a click adds the code to the search. Selected codes can be removed with **x**.

Norrpoint product fit:

- **Trion P2** (indoor, technical rooms, smaller areas): 71121, 71111, 71122, 68201, 68320, 71123, 71124, industrial plants.
- **Trion S2** (range, infrastructure, underground): 42110–42130, 08 mining/quarries, 02 forestry, 35–37 utilities.

## Practical search order

1. Start with **71121** only. That is the cleanest Swedish buyer code for handheld scanners.
2. Add **71122 + 71111 + 08120 + 42130 + 02409**.
3. Only then widen to construction **41–43** and filter by employee size, otherwise the list becomes too large.

## Use later, they are noisy

Only a subset of these companies need scanners. Review results manually.

| SNI | Industry | Why they are noisy |
| --- | --- | --- |
| **41** | Byggverksamhet | Very broad. Filter by size after the precise construction codes. |
| **10, 16, 20, 22–25, 28, 29** | Manufacturing | Only plants with complex interiors or process equipment are relevant. |
| **681** | Handel med eget fastighetsbestånd | Many are holding companies, not scanning users. |
| **7420** | Fotografisk verksamhet | Can include mapping firms, but most are ordinary photo studios. |
